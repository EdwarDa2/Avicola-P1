
========== src/domain/INTEGRACION.md ==========
# Guía de integración del motor de cálculo

Para quien conecta la interfaz y SQLite con el motor (`avicola-1.0.0`). El detalle de las fórmulas está en [README.md](README.md).

## 1. Regla de oro

La interfaz y la base de datos **solo llaman a `src/domain`**. Nadie recalcula fórmulas fuera del motor: ni en pantallas, ni en repositorios, ni en consultas SQL.

- Importa las funciones de `@/domain/calculators` y los catálogos (productos, escenarios, referencias de proteína) de `@/domain/calculators/scenarios`.
- Si una pantalla necesita un número que el motor no da, se agrega al motor con su prueba. No se calcula aparte.

## 2. Contrato

Todas las funciones son síncronas. Los errores de validación son `Error` con un mensaje en español listo para mostrar. Las funciones de cálculo también pueden lanzar `RangeError` si el resultado excede el rango entero seguro de JavaScript (`El resultado … excede el rango entero seguro.`), algo que solo pasa con entradas absurdas.

### Tipos de entrada comunes

`ConsumptionLine` (de `@/types`), una por grupo de edad:

| Campo | Tipo | Unidad y regla |
| --- | --- | --- |
| `ageGroup` | `'0-3' \| '4-8' \| '9-13' \| '14-18' \| '19+'` | grupo de edad |
| `peopleCount` | `number` | personas; entero ≥ 0 |
| `portionQty` | `number` | huevos por ocasión, o **gramos de carne cocida** por ocasión; ≥ 0 |
| `portionUnit` | `'piezas' \| 'gramos'` | informativo |
| `occasionsPerDay` | `number` | veces al día; ≥ 0, admite decimales |
| `daysPerWeek` | `number` | entero de 0 a 7 |

**Errores de líneas (L)**, en este orden, para el primer campo que falle:

- `Las líneas de consumo deben ser una lista.`
- `El número de personas debe ser un número finito (se recibió X).`
- `El número de personas no puede ser negativo (CP-17).`
- `El número de personas debe ser un número entero (se recibió X).`
- `La porción de consumo debe ser un número finito (se recibió X).`
- `La porción de consumo no puede ser negativa.`
- `Las ocasiones por día deben ser un número finito (se recibió X).`
- `Las ocasiones por día no pueden ser negativas.`
- `Los días por semana deben ser un número finito (se recibió X).`
- `Los días por semana deben estar entre 0 y 7 (CP-16).`
- `Los días por semana deben ser un número entero (se recibió X).`

**Errores de escenario (E):**

- `Escenario no encontrado: <clave>`
- `El escenario <clave> pertenece a <producto> y no se puede usar para <producto>.`
- `Al escenario <clave> le falta el parámetro <nombre>.` (error de datos del catálogo; no debería pasar)

| Producto | Claves |
| --- | --- |
| `hen_eggs` | `hen_conservative`, `hen_intermediate`, `hen_good_management` |
| `quail_eggs` | `quail_conservative`, `quail_intermediate`, `quail_good_management` |
| `chicken_meat` | `chicken_fast_growing`, `chicken_slow_growing` |

### `calculateQuailBreeding(desiredFemales, fertility, hatchability, survival, femaleRatio = 0.50)`

| | |
| --- | --- |
| Parámetros | `desiredFemales: number`: hembras de reemplazo, entero ≥ 1. `fertility`, `hatchability`, `survival`, `femaleRatio: number`: proporciones en (0, 1], por ejemplo `0.8`, **no** `80` |

| Errores | `La cantidad de hembras deseadas debe ser un número finito (se recibió X).` · `La cantidad de hembras deseadas debe ser mayor a cero.` · `La cantidad de hembras deseadas debe ser un número entero (se recibió X).` · `La fertilidad debe ser mayor a 0 y hasta 100% (CP-18).` · `La incubabilidad debe ser mayor a 0 y hasta 100% (CP-18).` · `La supervivencia debe ser mayor a 0 y hasta 100%.` · `La proporción de hembras debe ser mayor a 0 y hasta 100%.` · para una tasa no finita: `La fertilidad debe ser un número finito (se recibió X).` (igual con las otras tres) |

### `distributeLots(initialBirds, lotsCount)`

| | |
| --- | --- |
| Parámetros | `initialBirds: number`: aves, entero ≥ 0 (usa `primaryBirdsCount`). `lotsCount: number`: lotes, entero ≥ 1 |
| Devuelve | `LotDistribution`: `birdsPerLot` (por ejemplo 70 en 6 → `[12, 12, 12, 12, 11, 11]`), `lotsCount`, `totalBirds`, `explanation`. Con 0 aves: `lotsCount: 0`, `birdsPerLot: []` |
| Errores | `El número de lotes debe ser un número finito (se recibió X).` · `El número de lotes debe ser un entero positivo mayor a cero.` · `El número de aves a distribuir debe ser un número finito (se recibió X).` · `El número de aves a distribuir no puede ser negativo.` · `El número de aves a distribuir debe ser un número entero (se recibió X).` · `No se pueden repartir N aves en L lotes sin dejar lotes vacíos: usa como máximo N lotes.` |

### `calculateProtein(productCode, amount)`

| | |
| --- | --- |
| Parámetros | `productCode: ProductCode`. `amount: number`: huevos (unidades) o gramos de carne cocida; ≥ 0 |
| Devuelve | `number`: gramos de proteína, redondeados a 1 decimal |
| Errores | `Producto desconocido: <código>` · `La cantidad para calcular proteína debe ser un número finito (se recibió X).` · `La cantidad para calcular proteína no puede ser negativa.` |

Otras exportaciones útiles: `FORMULA_VERSION` (texto), `calculateWeeklyEggsDemand(lines)` y `calculateWeeklyMeatDemand(lines)` (demanda semanal sin escenario; lanzan errores L), y `validateConsumptionLines(lines)`.

## 4. Errores

Envuelve cada llamada en `try/catch` y muestra `error.message`. **No** tragues el error (`catch { return null }`) ni lo conviertas en 0: el usuario debe saber qué dato corregir, y un plan con error no se guarda.

```tsx
import React, { useMemo } from 'react';
import { Text, View } from 'react-native';

import { calculateHens } from '@/domain/calculators';
import type { CalculationResult, ConsumptionLine } from '@/types';

type Outcome = { ok: true; result: CalculationResult } | { ok: false; message: string };

function runHens(lines: ConsumptionLine[], scenarioKey: string): Outcome {
  try {
    return { ok: true, result: calculateHens(lines, scenarioKey) };
  } catch (error) {
    const message = error instanceof Error ? error.message : 'No se pudo calcular el plan.';
    return { ok: false, message };
  }
}

export function HensSummary({ lines, scenarioKey }: { lines: ConsumptionLine[]; scenarioKey: string }) {
  const outcome = useMemo(() => runHens(lines, scenarioKey), [lines, scenarioKey]);

  if (!outcome.ok) {
    // Se muestra el motivo y no se ofrece guardar.
    return <Text accessibilityRole="alert">{outcome.message}</Text>;
  }

  return (
    <View>
      <Text>
        {outcome.result.primaryBirdsLabel}: {outcome.result.primaryBirdsCount}
      </Text>
    </View>
  );
}
```

## 5. Mostrar resultados

- Las cantidades de aves, huevos a incubar y lotes ya son **enteros**: muéstralas tal cual.
- Las demandas (`weeklyDemand`, `annualDemand`) se entregan **sin redondear**; por ejemplo, `0.3333333333333333`. Redondea solo al mostrar y nunca guardes ni recalcules con el valor redondeado.
- El proyecto todavía no tiene un helper de formato. Hasta que exista, usa algo como esto:

```ts
/** Texto con hasta `decimals` decimales, sin ceros sobrantes: 71.76 → "71.76", 0.3333… → "0.33". */
export function formatNumber(value: number, decimals = 2): string {
  return String(Number(value.toFixed(decimals)));
}

/** Proporción a porcentaje para mostrar: 0.57 → "57 %" (evita 56.99999999999999). */
export function formatPercent(rate: number, decimals = 1): string {
  return `${formatNumber(rate * 100, decimals)} %`;
}
```

**Porcentajes de entrada:** el motor recibe **proporciones** (`0.8`), no porcentajes (`80`). Si el usuario teclea `80`, pásalo como `80 / 100`. El motor normaliza cada número a 15 cifras significativas, así que `33.3 / 100` se toma como 0.333 exacto. Si pasas `80` por error, el motor responde, por ejemplo, `La fertilidad debe ser mayor a 0 y hasta 100% (CP-18).`

## 6. Guardar en la base de datos

Con cada plan, guarda:

1. **Las entradas**: las `ConsumptionLine[]` y, si aplica, el número de lotes y las entradas de reproducción.
2. **La clave del escenario** (`scenarioKey`).
3. **El resultado completo** que devolvió el motor: `CalculationResult` y, si aplica, `LotDistribution` y `QuailReproductionResult`.
4. **`FORMULA_VERSION` como texto** (`'avicola-1.0.0'`).

¿Por qué? Un plan guardado es una foto: si mañana cambia una fórmula o un parámetro, los planes viejos deben seguir mostrando lo que se calculó ese día, y la versión dice con qué modelo se calculó. Al abrir un plan, **muestra el resultado guardado; no lo recalcules**. Recalcula solo si el usuario edita el plan, y entonces guarda el nuevo resultado con la versión vigente.

```ts
import { calculateHens, FORMULA_VERSION } from '@/domain/calculators';
import type { CalculationResult, ConsumptionLine, LotDistribution, QuailReproductionResult } from '@/types';

export interface PlanSnapshot {
  formulaVersion: string;
  scenarioKey: string;
  consumptionLines: ConsumptionLine[];
  lotsCount?: number;
  result: CalculationResult;
  lots?: LotDistribution;
  reproduction?: QuailReproductionResult;
}

export function buildHensSnapshot(lines: ConsumptionLine[], scenarioKey: string): PlanSnapshot {
  // Si calculateHens lanza error, no se construye ni se guarda nada.
  const result = calculateHens(lines, scenarioKey);
  return { formulaVersion: FORMULA_VERSION, scenarioKey, consumptionLines: lines, result };
}

// Para SQLite: JSON.stringify(snapshot) en una columna TEXT; al leer, JSON.parse y mostrar tal cual.
```

**Pendiente en el esquema actual** (`src/database/migrations/001_initial.ts`):

- `production_plans.calculation_version` es `INTEGER` y no puede guardar `'avicola-1.0.0'`. Hasta que haya una columna de texto, guarda `formulaVersion` dentro de `result_json`, como en `PlanSnapshot`.
- El `CHECK` de `production_plans.type` solo admite `chicken_eggs`, `broiler` y `quail_eggs`. No coincide con los `ProductCode` del motor y no permite `quail_meat`.
- `src/app/plan/create.tsx` guarda el literal `'V1.0'`; debe usar `FORMULA_VERSION`.

function percent(rate: number): number {
  return toNumber(mul(rate, 100));

/** Versión del modelo de cálculo que se guarda con cada plan (D-13, documentación §9.1). */
export const FORMULA_VERSION = 'avicola-1.0.0';

/**
 * F01 — Demanda semanal de huevos
 * E_sem = Σ (N_i * H_i * F_i * D_i)
 */
export function calculateWeeklyEggsDemand(lines: ConsumptionLine[]): number {
  validateConsumptionLines(lines);
  return toNumber(weeklyEggsExact(lines));
}

/**
 * F03 — Demanda semanal de carne cocida en kg
 * M_sem = Σ (N_i * M_i * F_i * D_i) / 1000
 */
export function calculateWeeklyMeatDemand(lines: ConsumptionLine[]): number {
  validateConsumptionLines(lines);
  return toNumber(weeklyMeatKgExact(lines));
}

/**
 * F02 & F01 — Cálculo para Huevos de Gallina (SRC-F1)
 */
export function calculateHens(
  lines: ConsumptionLine[],
  scenarioKey: string
): CalculationResult {
  const scenario = resolveScenario(scenarioKey, 'hen_eggs');

  validateConsumptionLines(lines);
  const weeklyEggs = weeklyEggsExact(lines);

/**
 * F08 — Distribución exacta de aves en lotes (SRC-F2, SRC-F3)
 * base = floor(A / L)
 * remainder = A mod L
 * lote_j = base + (j <= remainder ? 1 : 0)
 */
export function distributeLots(initialBirds: number, lotsCount: number): LotDistribution {
  // El núcleo valida L entero >= 1, aves enteras >= 0 y L <= aves (CP-19, D-11)
  const birdsPerLot = lotsCore(initialBirds, lotsCount);

  if (birdsPerLot.length === 0) {
    return {
      lotsCount: 0,
      birdsPerLot,
      totalBirds: 0,
      explanation: 'Sin aves para distribuir: no se generan lotes vacíos (CP-19).',
    };
  }

  const totalCalculated = birdsPerLot.reduce((a, b) => a + b, 0);
  if (totalCalculated !== initialBirds) {
    throw new Error(`Inconsistencia en suma de lotes: ${totalCalculated} != ${initialBirds}`);
  }

  return {
    lotsCount: birdsPerLot.length,
    birdsPerLot,
    totalBirds: initialBirds,
    explanation: `Distribución exacta de ${initialBirds} aves en ${lotsCount} lotes: ${birdsPerLot.join(', ')} aves. Suma total idéntica: ${totalCalculated} aves (RF-18).`,
  };
}

/**
 * Núcleos puros del motor de cálculo (`avicola-1.0.0`).
 *
 * Reciben los parámetros de forma explícita (sin escenarios) y calculan con racionales exactos
 * (D-10): no hay redondeos intermedios y cada `ceil` se aplica sobre el cociente exacto.
 * Las funciones públicas de `index.ts` resuelven el escenario y llaman a estos núcleos.
 *
 * Sin dependencias de React ni de base de datos.
 */
import type { ConsumptionLine } from '@/types';

import {
  add,
  bigintToSafeNumber,
  ceil,
  div,
  type Exact,
  floor,
  mul,
  rational,
  type Rational,
  sign,
  sub,
  toNumber,
} from '../math/rational';
import {
  assertFinite,
  assertNonNegative,
  assertNonNegativeInteger,
  assertRateInUnitInterval,
} from './validation';

/**
 * Valida una demanda (D-11, D-16): finita y >= 0. Devuelve `true` si es 0, para que el núcleo
 * responda 0 aves antes de validar los parámetros (CP-19).
 */
function isZeroDemand(value: Exact, label: string): boolean {
  if (typeof value === 'number') assertFinite(value, label);
  const valueSign = sign(value);
  if (valueSign < 0) {
    throw new Error(`${label} no puede ser negativa.`);
  }
  return valueSign === 0;
}

/** D-01: semanas por año para la demanda anual de carne. */
export const CALENDAR_WEEKS = 52;

/** Gramos por kilogramo (F03). */
const GRAMS_PER_KG = 1000;

/** Días por semana en el denominador de F02. */
const DAYS_PER_WEEK = 7;

/**
 * Σ (N_i · Q_i · F_i · D_i) exacto, en la unidad de la porción
 * (huevos para F01, gramos de carne cocida para F03).
 */
export function weeklyPortionSum(lines: readonly ConsumptionLine[]): Rational {
  let total: Rational = rational(BigInt(0));
  for (const line of lines) {
    const product = mul(
      mul(line.peopleCount, line.portionQty),
      mul(line.occasionsPerDay, line.daysPerWeek)
    );
    total = add(total, product);
  }
  return total;
}

/** F01 — E_sem = Σ (N_i · H_i · F_i · D_i), en huevos/semana. */
export function weeklyEggsExact(lines: readonly ConsumptionLine[]): Rational {
  return weeklyPortionSum(lines);
}

/** F03 — M_sem = Σ (N_i · M_i · F_i · D_i) / 1000, en kg de carne cocida/semana. */
export function weeklyMeatKgExact(lines: readonly ConsumptionLine[]): Rational {
  return div(weeklyPortionSum(lines), GRAMS_PER_KG);
}

/** F04 — M_año = M_sem · 52, en kg/año. */
export function annualMeatKgExact(weeklyKg: Exact): Rational {
  return mul(weeklyKg, CALENDAR_WEEKS);
}

export interface LayingParameters {
  /** P: postura diaria (proporción 0–1). */
  layingRate: number;
  /** U: aprovechamiento (proporción 0–1). */
  utilizationRate: number;
  /** S: margen de seguridad (proporción). */
  safetyMargin: number;
}

/**
 * F02 — G = ceil( E_sem · (1 + S) / (7 · P · U) ).
 * Orden (D-11): demanda negativa → error; E_sem = 0 → 0 sin mirar los parámetros;
 * con demanda positiva exige P y U en (0, 1] (CP-13) y S finito >= 0 (D-16).
 */
export function layingFemalesCore(weeklyEggs: Exact, params: LayingParameters): number {
  if (isZeroDemand(weeklyEggs, 'La demanda semanal de huevos')) return 0;
  assertFinite(params.layingRate, 'La tasa de postura');
  if (params.layingRate <= 0) {
    throw new Error('La tasa de postura no puede ser 0 o negativa con demanda positiva (CP-13).');
  }
  assertRateInUnitInterval(params.layingRate, 'La tasa de postura');
  assertRateInUnitInterval(params.utilizationRate, 'La tasa de aprovechamiento');
  assertNonNegative(params.safetyMargin, 'El margen de seguridad');
  const numerator = mul(weeklyEggs, add(1, params.safetyMargin));
  const denominator = mul(DAYS_PER_WEEK, mul(params.layingRate, params.utilizationRate));
  return bigintToSafeNumber(ceil(div(numerator, denominator)));
}

export interface MeatParameters {
  /** Y: kg de carne cocida comestible por ave. */
  meatYieldKg: number;
  /** m: mortalidad esperada (proporción 0–1). */
  mortalityRate: number;
  /** S: margen de seguridad (proporción). */
  safetyMargin: number;
}

export interface MeatBirds {
  /** A_s: aves para consumo (primera etapa de redondeo). */
  slaughterBirds: number;
  /** A_i: aves iniciales (segunda etapa de redondeo). */
  initialBirds: number;
}

/**
 * F05 y F06 en dos etapas de redondeo, a partir de la demanda anual exacta:
 *   A_s = ceil( M_año · (1 + S) / Y )
 *   A_i = ceil( A_s / (1 − m) )
 * No se usa la "fórmula para copiar" de un solo ceil de los PDF (ver README del dominio).
 * Orden (D-11): demanda negativa → error; M_año = 0 → 0/0 sin mirar los parámetros;
 * con demanda positiva exige Y > 0 (CP-14), m en [0, 1) (CP-15) y S finito >= 0 (D-16).
 */
export function meatBirdsCore(annualKg: Exact, params: MeatParameters): MeatBirds {
  if (isZeroDemand(annualKg, 'La demanda anual de carne')) {
    return { slaughterBirds: 0, initialBirds: 0 };
  }
  assertFinite(params.meatYieldKg, 'El rendimiento en carne');
  if (params.meatYieldKg <= 0) {
    throw new Error('El rendimiento en carne no puede ser 0 o menor (CP-14).');
  }
  assertFinite(params.mortalityRate, 'La mortalidad');
  if (params.mortalityRate < 0) {
    throw new Error('La mortalidad no puede ser negativa.');
  }
  if (params.mortalityRate >= 1) {
    throw new Error('La mortalidad no puede ser del 100% o superior (CP-15).');
  }
  assertNonNegative(params.safetyMargin, 'El margen de seguridad');
  const survival = sub(1, params.mortalityRate);
  const slaughter = ceil(div(mul(annualKg, add(1, params.safetyMargin)), params.meatYieldKg));
  const initial = ceil(div(rational(slaughter), survival));
  return {
    slaughterBirds: bigintToSafeNumber(slaughter),
    initialBirds: bigintToSafeNumber(initial),
  };
}

export interface BreedingParameters {
  /** f: fertilidad. */
  fertility: number;
  /** h: incubabilidad. */
  hatchability: number;
  /** s: supervivencia. */
  survival: number;
  /** p_hembras: proporción de hembras. */
  femaleRatio: number;
}

/**
 * F07 — H = ceil( R / (f · h · s · p_hembras) ), huevos a incubar.
 * R debe ser entero >= 1 (son hembras); f, h, s y p_hembras en (0, 1] (CP-18, enmienda D-11).
 */
export function eggsToIncubateCore(desiredFemales: number, params: BreedingParameters): number {
  assertFinite(desiredFemales, 'La cantidad de hembras deseadas', { feminine: true });
  if (desiredFemales <= 0) {
    throw new Error('La cantidad de hembras deseadas debe ser mayor a cero.');
  }
  assertNonNegativeInteger(desiredFemales, 'La cantidad de hembras deseadas', { feminine: true });
  assertRateInUnitInterval(params.fertility, 'La fertilidad', 'CP-18');
  assertRateInUnitInterval(params.hatchability, 'La incubabilidad', 'CP-18');
  assertRateInUnitInterval(params.survival, 'La supervivencia');
  assertRateInUnitInterval(params.femaleRatio, 'La proporción de hembras');
  const efficiency = mul(
    mul(params.fertility, params.hatchability),
    mul(params.survival, params.femaleRatio)
  );
  return bigintToSafeNumber(ceil(div(desiredFemales, efficiency)));
}

/**
 * F08 (regla del equipo) — base = floor(A/L); resto = A mod L; lote_j = base + (j <= resto ? 1 : 0).
 * Opera con enteros, así que no necesita racionales.
 *
 * Validaciones (CP-19, D-11): L entero >= 1; A entero >= 0; con A = 0 devuelve `[]` (no se generan
 * lotes vacíos); con L > A se rechaza, porque F08 produciría lotes de 0 aves. La fórmula no cambia.
 */
export function lotsCore(birds: number, lots: number): number[] {
  assertFinite(lots, 'El número de lotes');
  if (!Number.isInteger(lots) || lots < 1) {
    throw new Error('El número de lotes debe ser un entero positivo mayor a cero.');
  }
  assertNonNegativeInteger(birds, 'El número de aves a distribuir');
  if (birds === 0) return [];
  if (lots > birds) {
    throw new Error(
      `No se pueden repartir ${birds} aves en ${lots} lotes sin dejar lotes vacíos: usa como máximo ${birds} lotes.`
    );
  }
  const base = Math.floor(birds / lots);
  const remainder = birds % lots;
  const result: number[] = [];
  for (let j = 1; j <= lots; j++) {
    result.push(base + (j <= remainder ? 1 : 0));
  }
  return result;
}

/**
 * F13 — proteína = cantidad · proteína_por_base / unidades_de_base, redondeada a 1 decimal half-up.
 * `basisUnits` es 1 para huevos (g por unidad) y 100 para carne (g por 100 g cocidos).
 */
export function proteinGramsCore(amount: number, proteinPerBasis: number, basisUnits: number): number {
  assertFinite(amount, 'La cantidad');
  assertFinite(proteinPerBasis, 'La proteína de referencia');
  assertFinite(basisUnits, 'La base de la referencia');
  if (amount < 0) {
    throw new Error('La cantidad para calcular proteína no puede ser negativa.');
  }
  const grams = div(mul(amount, proteinPerBasis), basisUnits);
  const tenths = floor(add(mul(grams, 10), rational(BigInt(1), BigInt(2))));
  return toNumber(rational(tenths, BigInt(10)));
}

import type {
  ProductionPlan,
  CreatePlanInput,
  UpdatePlanInput,
  PlanData,
  ProductionType,
  PlanStatus,
} from '../../types/plan.types';

type SqlValue = string | number | null;

export interface PlanDb {
  runAsync(
    sql: string,
    params: SqlValue[]
  ): Promise<{ changes: number }>;

  getFirstAsync<T>(
    sql: string,
    params: SqlValue[]
  ): Promise<T | null>;

  getAllAsync<T>(
    sql: string,
    params: SqlValue[]
  ): Promise<T[]>;
}

interface PlanRow {
  id: string;
  profile_id: string;
  name: string;
  type: ProductionType;
  status: PlanStatus;
  input_json: string;
  result_json: string;
  calculation_version: number;
  created_at: string;
  updated_at: string;
}

function mapPlan(row: PlanRow): ProductionPlan {
  return {
    id: row.id,
    profileId: row.profile_id,
    name: row.name,
    type: row.type,
    status: row.status,
    inputs: JSON.parse(row.input_json) as PlanData,
    results: JSON.parse(row.result_json) as PlanData,
    calculationVersion: row.calculation_version,
    createdAt: row.created_at,
    updatedAt: row.updated_at,
  };
}

function validatePlan(
  input: Pick<
    ProductionPlan,
    'name' | 'inputs' | 'results' | 'calculationVersion'
  >
): void {
  if (!input.name.trim()) {
    throw new Error('El nombre del plan es obligatorio');
  }

  if (
    !Number.isInteger(input.calculationVersion) ||
    input.calculationVersion < 1
  ) {
    throw new Error('Versión de cálculo inválida');
  }

  for (const data of [input.inputs, input.results]) {
    if (
      data === null ||
      typeof data !== 'object' ||
      Array.isArray(data)
    ) {
      throw new Error('Los datos deben ser objetos JSON');
    }
  }
}

export function createPlanRepository(db: PlanDb) {
  async function findById(
    id: string
  ): Promise<ProductionPlan | null> {
    const row = await db.getFirstAsync<PlanRow>(
      'SELECT * FROM production_plans WHERE id = ?',
      [id]
    );

    return row ? mapPlan(row) : null;
  }

  return {
    // CREATE
    async create(
      input: CreatePlanInput
    ): Promise<ProductionPlan> {
      const status = input.status ?? 'draft';
      const calculationVersion =
        input.calculationVersion ?? 1;

      if (!input.id.trim() || !input.profileId.trim()) {
        throw new Error('ID del plan y perfil obligatorios');
      }

      validatePlan({
        name: input.name,
        inputs: input.inputs,
        results: input.results,
        calculationVersion,
      });

      const now = new Date().toISOString();

      await db.runAsync(
        `INSERT INTO production_plans (
          id, profile_id, name, type, status,
          input_json, result_json, calculation_version,
          created_at, updated_at
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
        [
          input.id,
          input.profileId,
          input.name.trim(),
          input.type,
          status,
          JSON.stringify(input.inputs),
          JSON.stringify(input.results),
          calculationVersion,
          now,
          now,
        ]
      );

      const created = await findById(input.id);

      if (!created) {
        throw new Error('No se pudo recuperar el plan');
      }

      return created;
    },

    // READ
    findById,

    async findByProfile(
      profileId: string
    ): Promise<ProductionPlan[]> {
      const rows = await db.getAllAsync<PlanRow>(
        `SELECT * FROM production_plans
         WHERE profile_id = ?
         ORDER BY created_at DESC`,
        [profileId]
      );

      return rows.map(mapPlan);
    },

    // UPDATE
    async update(
      id: string,
      changes: UpdatePlanInput
    ): Promise<ProductionPlan | null> {
      const current = await findById(id);

      if (!current) return null;

      const updated = {
        name: changes.name ?? current.name,
        status: changes.status ?? current.status,
        inputs: changes.inputs ?? current.inputs,
        results: changes.results ?? current.results,
        calculationVersion:
          changes.calculationVersion ??
          current.calculationVersion,
      };

      validatePlan(updated);

      const now = new Date().toISOString();

      await db.runAsync(
        `UPDATE production_plans SET
          name = ?,
          status = ?,
          input_json = ?,
          result_json = ?,
          calculation_version = ?,
          updated_at = ?
         WHERE id = ?`,
        [
          updated.name.trim(),
          updated.status,
          JSON.stringify(updated.inputs),
          JSON.stringify(updated.results),
          updated.calculationVersion,
          now,
          id,
        ]
      );

      return findById(id);
    },

    // DELETE
    async remove(id: string): Promise<boolean> {
      const result = await db.runAsync(
        'DELETE FROM production_plans WHERE id = ?',
        [id]
      );

      return result.changes > 0;
    },
  };
}

interface GroupInput {
  portion: string;
  occasions: string;
  days: string;
}

const toNumber = (value: string): number => {
  const parsed = Number(value.replace(',', '.'));
  return Number.isFinite(parsed) && parsed > 0 ? parsed : 0;
};

const buildDefaultInputs = (purpose: 'eggs' | 'meat'): Record<AgeGroupKey, GroupInput> => {
  const portion = purpose === 'eggs' ? '1' : '100';
  const days = purpose === 'eggs' ? '3' : '2';
  const record = {} as Record<AgeGroupKey, GroupInput>;

  for (const group of AGE_GROUPS) {
    record[group.key] = {
      // D-03: para la primera infancia no se sugiere una porción predeterminada.
      portion: group.key === '0-3' ? '0' : portion,
      occasions: '1',
      days,
    };
  }

  return record;
};
